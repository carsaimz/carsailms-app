# Carsai LMS — App

Aplicações oficiais do **Carsai LMS** para Android, Windows e Linux. Este repositório é o hub de construção e distribuição: cada versão publicada gera os instaladores e disponibiliza-os na página de descarga da plataforma.

## Descarregar

| Plataforma | Ficheiros |
|---|---|
| 🤖 Android (estável / beta) | `CarsaiLMS-v*-release.apk` · `CarsaiLMS-v*-beta.apk` |
| 🪟 Windows | `CarsaiLMS-Setup-v*.exe` · `CarsaiLMS-Portable-v*.exe` |
| 🐧 Linux | `CarsaiLMS-*-x86_64.AppImage` · `CarsaiLMS-*-amd64.deb` |

Descarga oficial: **https://carsailms.vercel.app/download-app** — mostra a versão, o tamanho e as novidades de cada lançamento. Dentro da app: **Configurações → Actualização** verifica e instala novas versões com o changelog.

## Novidades de cada versão

Cada lançamento traz changelog: na página de descarga, no diálogo de actualização dentro do app e na secção [Releases](../../releases).

## Sobre a plataforma

O [Carsai LMS](https://carsailms.vercel.app) é uma plataforma de ensino moçambicana: cursos com aulas em vídeo/PDF/ao vivo, testes corrigidos automaticamente, certificados com verificação pública, pagamentos M-Pesa/e-Mola, gamificação e apps em 8 idiomas (pt/en/es/fr/de/ar/sw/zh). O código-fonte vive no repositório privado `carsaimz/carsailms` (web + API + base de dados).

## Versões

Semver X.Y.Z publicado automaticamente a cada release do repo principal — cada tag `vX.Y.Z` corresponde à mesma versão nos 6 pacotes (APK estável, APK beta, Windows Setup, Windows Portable, Linux AppImage, Linux .deb).
