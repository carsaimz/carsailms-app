# CHANGELOG — Carsai LMS (apps)

Todas as alterações notáveis das apps (Android / Windows / Linux) da plataforma Carsai LMS.

A partir da **v2.120.0**, o CHANGELOG completo por versão vive no CORPO de cada release:
https://github.com/carsaimz/carsailms-app/releases — cada release vX.Y.Z traz a secção
`## [vX.Y.Z]` do CHANGELOG do código-fonte (repo privado carsaimz/carsailms), que documenta
também as novidades exclusivas da web.
